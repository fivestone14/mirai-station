Anatomy of one firing, real seconds

  1. 1 scan writes the diary row, payload built, gate decides 0 to about 1 s, code only
  2. 2 observer, Sonnet 5, reads the payload about 4 s on the Scene Payload, 15 s on the Strikes Payload, 100 s timeout
  3. 3 reviewer, Haiku 4.5, deletes any forecast sentence a few seconds, 40 s cap
  4. 4 read row written the sentence that stands until the next call
  5. 5 dashboard sees it the page polls every 10 s; a background tab once a minute
